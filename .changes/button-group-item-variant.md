**Button group items.** An item can set its own `variant`, and an icon-only item can set `width` to `narrow`, `default` or `wide`. The group's variant stays the default, including after it changes, for an item that has no variant of its own. The group's size still sets every item's height. Only an item that sets `width` keeps the icon button's width; an inherited width or a width class still follows the group's square. An icon-only item takes a variant the icon button draws, and `text` is drawn as `standard`.
